## 🚀 Local Development

To run this portfolio locally:

### 1. Install dependencies

```bash
npm install
```

### 2. Launch the development server

```bash
npm run dev
```

Open [**http://localhost:4321**](http://localhost:4321/) in your browser to see the result! 🚀

## 🧞 Commands

|     | Command          | Action                                        |
| :-- | :--------------- | :-------------------------------------------- |
| ⚙️  | `npm run dev`    | Launches a local development server at `localhost:4321`.  |
| ⚙️  | `npm run build`  | Checks for errors and builds for production in `./dist/`.      |
| ⚙️  | `npm run preview`| Local preview at `localhost:4321` |
